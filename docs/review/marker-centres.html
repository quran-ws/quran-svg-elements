Where does the number sit?

Drag the number onto where it belongs. Scroll or use the slider to size it. —

Each marker starts with a derived guess: the centre of its inner region, because that is where the number lives on a symmetric design. Where the design has a pendant or a tail the guess will be low — drag it up. Only the markers you actually move are recorded as corrections, so leaving a good one alone is itself an answer.
