The pipeline reads the printed artwork and gives every stroke a name: which ayah, which word, which ligature, which mark. Nothing is redrawn — the ink below is the print's own outlines, wrapped in structure you can select, crop and recolour. This page shows the ways to use that.

Embed a whole page

The build writes one file per page. It is an ordinary SVG with a fixed viewBox, so it scales to any width and prints at any size. Drop it in as an image when you only need the picture; inline it when you want to select things inside it.

g.ayah[data-surah][data-ayah]

Embed a single ayah

An ayah is a group — sometimes several, when it runs across a line break. Keep its words, drop the rest, then let the browser measure what is left and write a new viewBox. The crop keeps the print's own line breaks, because that is how the ayah is actually set on the page.

Embed part of an ayah

Words are numbered inside their ayah, so any run of them crops the same way — one word for a vocabulary card, a phrase for a citation. The words carry their text three ways at once (data-uthmani, data-imlaei, data-qpc), which is what makes a crop searchable rather than just a picture.

Recolour by what the ink means

Every path in the file is fill="#231f20", and every path also says what it is. A CSS rule beats the attribute, so colour follows meaning: letters one way, vowel marks another, the dots that distinguish letters another again. No re-export, no second file.

Swap the ayah end-marker

The marker that closes an ayah is two things in one group: the printed rosette, and the ayah number drawn inside it. They are separate paths, so the ornament can be replaced without touching the number — useful when the mushaf's own rosette is heavier than a screen layout wants.

g.line[data-line]

Open up the spacing

The fifteen lines are separate groups and the words inside them are too, so the page can breathe in both directions without touching a single glyph. Lines move as one, words slide apart along their line, the ayah end-markers ride with the line and the word run they belong to, and the viewBox grows to match. Every letter keeps its exact printed shape.

Spacing

The end-markers are stored outside the lines, so they are matched to a line — and to a place in that line's run of words — by position before anything moves. The same trick works for anything you draw on top of the page.
