The same page,
steered without a line of JavaScript

Everything below is a radio button, a sibling selector and a URL fragment. The file carries a <view> per ayah, line and word, a stylesheet that answers to :target, and a spacing index on every line and every word. Nothing on this page runs. The scripted demo is here.

Crop and isolate an ayah

A <view> sets the frame; a :target rule inside the file hides the neighbours. The browser does both from the fragment, in a plain image tag.

Ayah

<!-- the whole thing -->
<img src="003-embed.svg#v-ayah-10">

/* what the file does with it, internally */
svg:has(#v-ayah-10:target) g.word:not([data-ayah="10"])
  { display: none }

Eleven image tags, one per ayah, all hidden but the checked one — the file is fetched once and the fragment does the rest.

Swap the ayah ornament

The alternates ride along inside the file as <use> references, all hidden but one. The fragment picks which; the printed rosette steps aside. The ayah numbers never move.

Ornament

<img src="003-embed.svg#set-rosette">

/* one rule serves the fragment and the class alike */
svg.orn-rosette .alt-rosette,
svg:has(#set-rosette:target) .alt-rosette { display: inline }

--gap · --wgap

Open up the spacing

Each line carries its own index, each word its place in the line. Two custom properties move all of it — and the ayah end-markers, which carry both indices too.

Spacing

svg { --gap: 4; --wgap: 3 }

/* the file's own rules */
g.line { transform: translateY(calc((var(--mid) - var(--i)) * var(--gap) * 1px)) }
g.word { transform: translateX(calc((var(--kmid) - var(--k)) * var(--wgap) * 1px)) }

CSS cannot rewrite a viewBox, so the file sets overflow: visible and the frame is given the extra room. This is the one place where the scripted version does something CSS cannot.

path[data-kind] · path[data-mark-family]

Recolour by meaning

This one never needed script. Every path says what it is, and a CSS rule outranks the fill attribute it was written with.

Preset

path[data-kind="mark"]        { fill: #a07514 }
path[data-mark-family="dots"] { fill: #a07514 }
.ayah-marker path             { fill: #c2921f }

[data-ge~] · [data-le~]

Any run of words, in one selector

CSS has no way to say "between 4 and 7". So every word carries the two lists that make it sayable: data-ge holds its index and everything below, data-le its index and everything above. A word is in the run when both lists contain the ends.

Words of 2:13

g.word:not([data-ayah="13"][data-ge~="4"][data-le~="7"])
  { display: none }

Framing an arbitrary run still needs a viewBox, which the URL can carry: #svgView(viewBox(180,331,150,32)). Only the isolation is done here.
